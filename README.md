# Учебный frontend-проект

## Описание
Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».
Тема проекта: многостраничный сайт интернет-магазина или каталога услуг.

## Структура проекта
- `index.html` — главная страница;
- `css/style.css` — файл стилей;
- `images/` — папка для изображений;
- `.gitignore` — список файлов, исключённых из Git;
- `README.md` — описание проекта.

## Используемые технологии
- HTML;
- CSS;
- Git;
- GitHub.

## Реализованные элементы интерфейса
- кнопки заказа в карточках товаров;

- базовая HTML-валидация;
- базовая JS-обработка формы;
- сообщение об успешной отправке.

## Практическая работа 3: форма и модальное окно
- Реализована форма заявки с полями для ввода данных.
- Добавлено модальное окно для оформления заявки.
- Настроена базовая проверка введённых данных.
- Реализована обработка отправки формы средствами JavaScript.

## Практическая работа 4: CSS-архитектура и состояния интерфейса
- Организованы CSS-стили по тематическим разделам.
- Добавлены CSS-переменные в `:root` для цветов, отступов, скруглений и ширины контейнера.
- Для повторяющихся значений используется функция `var()`.
- Добавлены состояния наведения `:hover` и клавиатурного фокуса `:focus-visible`.
- Добавлено оформление отключённых кнопок с помощью `:disabled`.
- Предусмотрено визуальное выделение полей с атрибутом `aria-invalid="true"`.
- Улучшено оформление кнопок, карточек товаров, формы и модального окна.
- Предусмотрена визуальная проверка состояний элементов в браузере.

## Результаты практической работы 4
CSS-код структурирован с использованием переменных и повторно используемых значений. Для интерактивных элементов предусмотрены состояния наведения, фокуса, отключения и ошибки формы.
