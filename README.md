# Учебный frontend-проект

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема контрольной работы №1: «HTML и CSS: разработка многостраничного сайта».

Проект представляет собой учебный многостраничный интернет-магазин, разработанный с использованием HTML, CSS и JavaScript.

**ФИО:** Коржиков Александр

## Страницы сайта

* `index.html` — главная страница с преимуществами и популярными товарами;
* `catalog.html` — каталог товаров;
* `product.html` — страница отдельного товара;
* `order.html` — страница оформления заявки;
* `contacts.html` — контактная информация и раздел часто задаваемых вопросов.

## Как запустить проект

1. Склонировать репозиторий или скачать исходные файлы.
2. Открыть папку проекта в Visual Studio Code.
3. Открыть `index.html` в браузере.
4. Для удобства можно использовать расширение Live Server.
5. Перейти между страницами через навигационное меню.
